A Python program (standard library only, deterministic, no network) that writes one line — a one-star review of Monday written as if Monday were a restaurant — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`). The line is a single line of plain text, at most 25 words and at most 180 characters.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the review text to `entry.txt` in the output directory.
